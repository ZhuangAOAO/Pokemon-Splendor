# 璀璨宝石 · 宝可梦（Splendor Pokémon 桌游复刻）

用**纯原生 HTML / CSS / JavaScript** 制作的网页版桌游，复刻了韩国 Korea Boardgames 官方授权的
《璀璨宝石：宝可梦》核心玩法。支持**本地单机**和**局域网联机**，零第三方依赖。

## 🚀 如何运行

### 本地单机模式（一个人 / 热座 / 演示）

1. 双击打开 `index.html`（用 Chrome / Edge 浏览器）
2. 选择玩家：2-4 人，每位可以是人类、电脑·简单或电脑·困难
3. 选择目标分数，点击「开始游戏」

### 局域网联机模式（每人一台电脑）

1. 在一台电脑上打开命令行，进入本文件夹，运行：
   ```bash
   node server.js
   ```
   启动后会打印地址，例如 `http://192.168.1.4:3000`
2. 所有人都用浏览器打开这个地址（同一 Wi-Fi / 局域网）
3. **第一次使用先注册账号**（用户名 2~12 字、密码 ≥6 位），管理员审核通过后才能游戏
4. **第一个加入房间的人自动成为房主**：可以添加电脑玩家、设置目标分、点「开始游戏」
5. 对局中：轮到你时才会显示行动按钮；断线的玩家轮到自己时 30 秒后自动跳过（可重连）
6. 对局中任何玩家可点顶栏「结束对局」发起**投票**：全体在线玩家同意即结束（有人反对则取消）；
   全员离线时对局自动结束；顶栏「记录」可查看对局日志（服务器同时落盘到 `logs/server.log`）

### 账号系统（注册申请 → 管理员审核，数据存 MySQL）

1. **配置数据库连接**：在 `data/` 下新建 `db.json`（已加入 .gitignore，不会进 git）：
   ```json
   { "host": "127.0.0.1", "port": 3306, "user": "root", "password": "你的密码", "database": "splendor" }
   ```
   服务器启动时自动创建 `splendor` 数据库和表（只碰自己的库，不影响其他数据）
2. **创建管理员账号**（只需一次）：
   ```bash
   node 工具/初始化管理员.js 你的用户名 你的密码
   ```
3. **审核**：管理员浏览器打开 `http://服务器地址/admin.html`，登录后对申请「通过 / 拒绝」
4. 玩家注册后登录时提示"等待审核"；被通过后首次登录会弹出欢迎提示
5. 密码 scrypt 加盐哈希后存入数据库，不存明文；战绩表 stats 记录胜场/场次/平均分/进化次数

### 一键开关服务器（Windows 双击即用）

- 双击 **`启动服务器.bat`**：启动服务器并自动打开浏览器（已运行则只开页面）
- 双击 **`停止服务器.bat`**：关闭服务器

### 自动化测试

```bash
node 工具/sim.js 100 3 18   # AI 对战模拟：校验规则守恒与平衡性
node server.js              # 先启动服务器
node 测试/e2e-test.js        # 联机端到端回归测试（另开一个命令行窗口）
```

## 🔑 密钥管理（2026-09-17）

数据库密码与测试用管理员密码**都不应该放在项目目录里** —— 只要密钥跟着项目走，整个文件夹拷给别人 / 打进备份就会泄露。

**推荐做法：环境变量**

```bash
export SPLENDOR_DB_HOST=127.0.0.1
export SPLENDOR_DB_PORT=3306
export SPLENDOR_DB_USER=root
export SPLENDOR_DB_PASSWORD='你的数据库密码'
export SPLENDOR_DB_NAME=splendor
```

测试用管理员凭据同理：`SPLENDOR_TEST_ADMIN` / `SPLENDOR_TEST_ADMIN_PASSWORD`。

**优先级**：环境变量 > `data/db.json` > 默认值；统一入口是根目录的 `db-config.js`（server / 工具 / 测试都走它，不再各自读文件）。
`data/db.json` 与 `测试/凭证.json` 仍然可用（两者已被 `.gitignore` 排除），但**只适合本机开发**。示例见 `db.example.json`、`测试/凭证.example.json`。

**线上（systemd）**：密码放 `/etc/splendor.env`（权限 600），unit 里用 `EnvironmentFile=` 引入。

## 🎮 玩法速览

- **目标**：率先达到目标分数触发终局，完成当前一轮后分数最高者获胜
- **每回合五选一**：
  1. **拿取精灵球** — 拿 3 个不同颜色的球，或拿 2 个相同颜色的球（供应区该色 ≥4 个）
  2. **收服宝可梦** — 支付卡牌费用（已拥有的宝可梦提供永久加成自动抵扣），获得分数
  3. **预约宝可梦** — 收进预约区（最多 3 张）+ 获得 1 个**大师球**（万能球）；
     也可以点击左侧牌堆**盲抽**一张（只有你自己知道）
  4. **退还精灵球** — 把 1 个球退回供应区（防卡死的周转行动）
- **进化**：回合结束可免费进化 1 只（条件印在未进化的卡上，用永久加成凑）
- **稀有/传说**：各只展示 1 张；费用含大师球（必须支付）、不能预约；提供**双倍加成**
- **手牌上限**：精灵球（含大师球）最多 10 个
- 宝可梦分五类：一阶（0~1分）、二阶（1~3分）、三阶（3~5分）、稀有（0分·双倍加成）、传说（2分·双倍加成）

详细规则见游戏内的「规则说明」弹窗。

## 🏗️ 架构（面向未来部署）

```
浏览器(客户端)  ──POST 行动──►  服务器(Node)  ──SSE 推送状态──►  所有浏览器
   只负责渲染和操作           服务器权威：对局状态唯一        SSE 自动重连
```

- **服务器权威制**：对局状态只存在于服务器，客户端只发送行动、接收完整状态并渲染。以后部署到公网服务器时客户端一行都不用改
- **零依赖**：通信用 HTTP + SSE（Server-Sent Events）+ POST 实现，不需要 npm install，离线局域网可用；以后想换 WebSocket 只需改 `server.js`
- **代码三分离**：`game-core.js`（规则逻辑，浏览器/服务器共用同一份）、`client.js`（界面）、`server.js`（网络编排）
- **部署到公网**：把整个文件夹拷到云服务器，`node server.js` 即可（可在 config.js 改端口）

## 🎛️ 如何调整数值

**所有数值都在 `config.js` 里，改完保存即生效（本地刷新浏览器 Ctrl+F5；联机需重启服务器）：**

- **改某只宝可梦的强度** → 找到卡牌表中它的那一行，直接改分数或费用，例如：
  ```js
  ['皮卡丘', 1, 0, 0, 0, 3, 0, 0, 'pink', 0], // 0分·费3
  //  名称     阶  分  红 蓝 黑 粉 黄  加成色 大师球费
  ```
  把它改成 `1, 1, ...` 就是 1 分；把费用改成 `0,0,4,0,0` 就是费 4
- **稀有/传说卡** → 阶填 `4`（稀有）或 `5`（传说），最后一个数是**大师球费**（必须用大师球支付）；
  它们提供双倍加成、不可预约
- **加新宝可梦** → 复制一行，改名称和数值即可（牌堆自动变大）
- **改规则** → `RULES`：手牌上限、大师球数量、预约上限、目标分选项……
- **改 AI 强弱** → `AI_CONFIG`：思考时间、简单电脑乱走概率、困难电脑前期策略
- **改联机** → `NETWORK`：端口、断线跳过秒数、人数上限
- **整体重新平衡卡牌** → 修改 `工具/生成卡牌表.js` 的费用模板，运行 `node 工具/生成卡牌表.js`
  （⚠️ 会覆盖 config.js 里手工改过的卡牌数值）

## 🖼️ 卡牌图片（可选）

想给卡牌用上真实卡面图片（例如官方卡牌扫描件）：

1. **命名规则**：文件名 = config.js 卡牌表里的宝可梦名，放在 `pictures/` 文件夹，例如 `pictures/皮卡丘.jpg`
   ⚠️ 卡牌表里的名字必须**唯一**——官方版同一只宝可梦有多张卡（费用不同），重复的加后缀区分：
   `皮卡丘` 和 `皮卡丘2`，图片对应 `皮卡丘.jpg` 和 `皮卡丘2.jpg`
2. 运行 `node 工具/检查图片.js`：生成「图片命名对照表.txt」（全部名字清单），并报告哪些已命名、缺失、多余
3. 图片加载成功会直接作为**卡面**显示；没有图片的卡牌自动退回程序绘制的样式——可以一张张慢慢补
4. **对齐官方数值**：如果卡面上印着官方费用/分数，对照着修改 config.js 卡牌表的对应行
   （每行 = 一张卡，可增删行让卡牌表与图片完全一致；改完建议跑 `node 工具/sim.js` 验证平衡）
5. 「稀有/传说」卡牌已支持（大师球费用 + 双倍加成），图片按宝可梦名放入 `pictures/` 即可
