# ② 大厅布局：三套候选方案 + 验收记录

> 2026-09-18 UI 线（18:00 开工）。**原型阶段，未动生产代码**。
> 与之配套的信息架构说明见 `demo/lobby-ia.md`。

## 怎么看

启动本地服务（`node server.js`）后：

- 方案 A（左侧竖向导航栏）→ http://localhost:3000/demo/lobby-plan-a.html
- 方案 B（顶部胶囊导航 + 卡片网格）→ http://localhost:3000/demo/lobby-plan-b.html
- 方案 C（左 hero 主按钮 + 右侧功能网格）→ http://localhost:3000/demo/lobby-plan-c.html

截图证据：`demo/shots/lobby-plan/{a,b,c}-1280x720.png`、`{a,b,c}-844x390.png`
（1280×720 = 电脑横屏；844×390 = iPhone 横屏。⑤ 既已定「横屏优先」，三套都只做一套横向布局。）

## 三套方案怎么选（差异轴：导航形态 / 内容区排布 / 主按钮位置）

| | A 左侧竖栏 | B 顶部胶囊 + 卡片网格 | C 左 hero + 右 2×2 网格 |
|---|---|---|---|
| 导航形态 | 贴左竖栏，图标+文字竖排 | 顶部横向胶囊 tab | 无独立导航：hero 卡即主入口，其余是功能卡 |
| 内容区 | 单列分栏（右区） | 卡片网格 | 左 hero + 右网格 |
| 主按钮位置 | 竖栏顶部「开始对局」 | 内容区 hero 条内「进入游戏」 | 左栏 hero 卡内「进入游戏」 |
| 加第 6 个入口 | 竖栏多一行（天然可滚动，**最省事**） | 胶囊会开始挤，需要再设计收纳 | 右侧网格多一格；超过 7 个要加「更多」抽屉 |
| 内容区可用宽度 | 最窄（844px 下只剩约 640px） | 最宽 | 中等 |
| 适合 | 入口会一直加、要求入口同级等权 | 入口 ≤6 个、想「一眼看到全部玩法」 | 想强调「一键进入游戏」、入口分层 |

**我的建议（推断，供濠哥判断）**：若按待办 ③④ 还会继续加「挑战冠军 / 光荣榜 / 未来的赛季公告」，
**A 的扩展成本最低**（加一项 = 数组加一行，竖栏自带滚动）；
但 **A 牺牲了开场气场**（竖栏把 44px 红金标题压到 20px 以内）。
如果濠哥更看重「大厅该像大厅、一键入局」，**C** 的按钮层级最干净（全屏只有 1 个红色主按钮）。
B 的两层导航（胶囊 + 卡片都能去同一个地方）有重复感，是最需要慎选的一套。

## 我的验收结果（实测，非 CC 自述）

用 Edge 打开三页，逐项在 CDP 里取 DOM 实测值：

| 检查项 | A | B | C |
|---|---|---|---|
| 5 个一级入口都是 `<button>`（非文字链） | ✅ 5 个 | ✅ 5 个 | ✅ 5 个 |
| 点「光荣榜」能切到占位区、不报错 | ✅ 仅 `sec-hall` 可见，`aria-current` 落在该项 | ✅ 同左 | ✅ 同左 |
| 1280×720 横向溢出 | 无（scrollWidth=1280） | 无 | 无 |
| 844×390 横向溢出 | 无 | 无 | 无 |
| 右上角收纳四项同一行 | ✅ 同一 y 坐标 | ✅ 同一 y 坐标 | ✅ 同一 y 坐标 |
| 页内 `<style>` 新增十六进制配色 | 无（仅精灵球 `--bc/--band`，照抄现有写法） | 无 | 无 |
| `prefers-reduced-motion` 降级分支 | ✅ | ✅ | ✅ |
| 导航数据驱动（`const NAV` + 循环渲染） | ✅ | ✅ | ✅ 且第 6 项「赛季公告」已真实落地可点 |

## 已知缺陷（**没修完，交付前须知**）

1. **B @ 844×390：卡片标题被裁到看不见**。为满足「不许逐字竖排」加了 `nowrap + ellipsis`，
   但卡片只有 124px 宽，结果标题被截成图标后一小截字符，只剩「进入 →」可读 —— **信息量反而降了**。
   建议：844px 下把 4 张卡改成 2×2 两行，或标题恒显、说明文字才截断。
2. **C @ 1280：网格卡片被拉到 632px 高**，内容只占顶部一小块、「进入 →」孤零零钉在底部，大片留白；
   同页左下的「挑战冠军」卡渲染成**空白白块**（文字未显示）。C 的固定高度/`overflow` 规则需要重做。
3. 逐帧截图存在**抓拍时机**问题：A@1280 有一张抓到 section 淡入中途（实测该 section `opacity:1`、无运行中动画，
   属截图时机，非缺陷）。后续截图前应先等动画结束。
